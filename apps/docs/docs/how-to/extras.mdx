# Extra agents

The standard project directory is `.agents/skills`. Cursor, Codex, and other agents that read it need no additional configuration.

An **extra destination** is for an agent that uses a different project directory. The common case is Claude Code, which reads `.claude/skills`.

## This activation

```bash
skl use writing-tests -a claude-code
```

`claude` is an alias for `claude-code`. Use `-a <id>` for any catalog agent that has its own project directory. Cursor and Codex cannot be added because they already read `.agents/skills`.

## Sticky extras

```bash
skl targets
skl targets add claude-code
skl targets remove claude-code
```

`skl targets` lists `.agents/skills` and any **sticky extras** stored in `~/.config/skl/config.toml` under `[targets].extra`. These extras apply to future `skl use` commands on the same machine.

`skl init` and `skl doctor` may ask once whether to configure extras. The prompt is skipped in CI, when `SKL_NO_PROMPT` or `SKL_YES` is set, or when stdin is not interactive.
