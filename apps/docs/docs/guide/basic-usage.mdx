# Basic usage

These commands assume skl is installed. For sync, see [Setting up sync](/guide/sync).

One-liner: **edit the library. Refresh projects. Capture only when the project temporarily won.**

```bash
skl edit writing-tests   # library in $EDITOR
skl sync                 # optional; other machines
skl use --all            # or skl refresh
```

No `--force` on that path.

## Create

```bash
skl create writing-tests
```

`skl new` is an alias. The command creates `~/.local/share/skl/skills/writing-tests/SKILL.md` with `name` and `description` frontmatter, then opens `$VISUAL` or `$EDITOR` (falling back to `vi`).

Names cannot start with `.` or contain `/` or `\`. Creating a name already in the library fails; run `skl edit writing-tests` instead.

If the editor fails, the skill is still on disk.

## Edit

```bash
skl edit writing-tests
```

Opens the **library** `SKILL.md` in `$VISUAL` or `$EDITOR`. It does not open `.agents/skills` or other project copies. Both editor variables unset is an error.

If the current git root (or cwd) already lists the skill in `skills.toml`, skl hints `skl use --all`.

If you edited a project copy by mistake:

```bash
skl capture writing-tests           # promote; fails on clash
skl capture writing-tests --force   # overwrite the library
skl use --all
```

## Use

```bash
skl use writing-tests
```

`skl use` makes a library skill available in the current project. It creates `.agents/skills/writing-tests` as a real copy (materialize) and adds the name to `skills.toml`. Use `--link` for a local symlink. `--all` rematerializes every listed skill from this machine's library, including sticky extras such as `.claude`. Managed projections refresh without `--force`.

```bash
skl use
```

With no arguments, `skl use` lists skills already active in the current project.

```bash
skl use --all
```

`--all` (also `skl refresh`) recreates every skill listed in `skills.toml` from this machine's personal library. If a listed skill is missing locally, sync first, then run `skl use --all` again. `--force` is only for clobbering unmanaged dests, not everyday refresh.

```bash
skl use writing-tests -a claude-code
```

`-a` / `--agent` adds an additional project directory for this activation. Repeat the flag for multiple agent IDs. `claude` is an alias for `claude-code`.

Cursor and Codex already read `.agents/skills`. Do not add them as extras.

`--project DIR` sets the project root. Default is the current directory.

## Unuse

```bash
skl unuse writing-tests
```

`skl unuse` removes the project's copy or link and removes the name from `skills.toml`. It leaves the personal library unchanged.

## List, status, delete

```bash
skl list
skl status
skl delete writing-tests
```

`skl list` shows locally indexed skills from `state.db`. When you are logged in, it also shows whether each is present remotely.

`skl status` prints `api_base`, whether a device token is present, config and `state.db` paths, auto-sync prefs, local skill count, and last sync.

`skl delete` removes the skill from SKL and deletes the local library copy. It does not change project directories or home agent directories. Because it calls the API, you must be logged in.

## Migrate old project links

```bash
skl migrate targets
skl migrate targets --prune-old
skl migrate targets --project DIR
```

`skl migrate targets` moves old `.claude` and `.cursor` project links to `.agents/skills`. `--prune-old` removes the old links after the new destination exists. `skl migrate projections --materialize` converts symlink activations to copies. `skl use` does not run these migrations. `skl doctor` warns when it finds the old layout or a link projection.

## Update the CLI

```bash
skl update
```

`skl update` replaces this `skl` binary with the latest GitHub Release. See [Installation](/guide/installation) and [skl update](/reference/update).
