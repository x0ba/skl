# Getting started

This guide covers the setup steps in order. For the short version, see the [home page](/).

Setup has four steps. Only installation is required.

1. Install skl
2. Import existing skills, if you have any
3. Log in and sync, if you want the library on more than one machine
4. Open the TUI and use a skill in a project

## 1. Install

The install script downloads the binary and can guide you through the initial setup:

```bash
curl -fsSL https://www.tryskl.fyi/install.sh | sh
```

In an interactive terminal, it asks whether to log in and import existing skills. In CI or a non-interactive shell, it installs only the binary.

Want flags and `PATH` notes? See [Installation](/guide/installation).

After installation, running `skl` in an interactive terminal opens the TUI.

## 2. Import existing skills

`skl init` copies skills from home agent directories into the personal library. It does not change the source directories.

```bash
skl init
```

Skip this if you have nothing to import. You can create a skill later with `skl create`. Details are in [Import existing skills](/guide/import).

## 3. Set up sync (optional)

Sync backs up the personal library and makes it available on other machines. You can use the hosted API or [run the server yourself](/self-hosting).

```bash
skl login
skl sync
```

`skl login` prints a verification URL and a user code. Approve the device in the browser. The **device token** is stored in `~/.local/share/skl/state.db`.

Without sync, the personal library remains only on this machine. [Setting up sync](/guide/sync) explains adding a second machine, resolving conflicts, and server access to skill data.

## 4. Use a skill

Create one if the library is empty:

```bash
skl create writing-tests
```

Change into a project and activate it:

```bash
cd /path/to/project
skl use writing-tests
```

`skl use` creates `.agents/skills/writing-tests` and adds the name to `skills.toml`. By default it creates a symlink to the personal library; if that fails, it copies the skill instead.

Running `skl` opens the two-pane browser. See [The TUI](/guide/tui) for keybindings and [Basic usage](/guide/basic-usage) for everyday commands.

## Getting help

File an issue at [github.com/x0ba/skl/issues](https://github.com/x0ba/skl/issues). Run `skl doctor` first and include its output.
