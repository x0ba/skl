# Import existing skills

Use two commands to add skills to the personal library. `skl init` imports from home agent directories. `skl capture` imports a skill from a project.

## Init

```bash
skl init
```

`skl init` finds skills in supported home directories and copies each one that is not already in `~/.local/share/skl/skills`. It leaves the source directories unchanged and never overwrites an existing library skill.

Roots include:

- `~/.agents/skills`
- `~/.config/agents/skills`
- `~/.claude/skills`
- `~/.cursor/skills`
- `~/.codex/skills`
- other catalog globals on this machine

`skl doctor` lists the directories it can find. After `init`, you can sync the library. Sync does not change those home directories.

Init may ask once whether you want **sticky extras** such as Claude Code. See [Extra agents](/guide/agents).

## Capture

```bash
skl capture writing-tests
skl capture .agents/skills/writing-tests
```

`skl capture` copies a project skill into the personal library. It resolves a path or name from `.agents/skills` and any configured extra agent directories.

After a successful capture, the project directory is replaced with a symlink to the library copy. Use `--keep-copy` to leave the project directory as a real copy.

### Flags

- `--force` overwrites an existing library skill of the same name.
- `--as NAME` stores the skill under a different name.
- `--keep-copy` copies the skill into the library and leaves the project directory as a real copy.
- `--project DIR` sets the project root. Default is the current directory.

If the library already has that name, use `--force` or `--as`; otherwise capture fails. The source must be a directory containing `SKILL.md`.
