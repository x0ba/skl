# The TUI

Running `skl` in an interactive terminal opens the two-pane skill browser. `skl tui` and `skl ui` do the same.

```bash
skl
skl tui
skl ui
```

`--no-tui` or `SKL_NO_TUI=1` prints help instead of opening the fullscreen interface.

Browse works offline. Sync from the TUI needs login.

## Keys

```text
↑/↓ or j/k     move
[ / ]          scroll preview
Ctrl-j / Ctrl-k  scroll preview
/              search
n              new skill
e              edit SKILL.md
u              use
U              unuse
d              delete
s              sync
r              refresh
?              help
q or Esc       quit
```

`n` runs `skl create`. `e` opens `SKILL.md` in `$VISUAL` or `$EDITOR`. `u` and `U` run `skl use` and `skl unuse` for the selected skill in the current project. `d` runs `skl delete`. `s` runs `skl sync` and waits for it to finish. `r` reloads the local library and `state.db`.

Esc leaves search, help, create, or the delete confirm, then quits from the list.
