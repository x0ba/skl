# skl login

Authorize this device, then store its token in local state.

## Synopsis

```bash
skl login
```

## Flags

None.

## What it writes

- Stores the device token in `state.db` (`meta.device_token`)
- Writes `api_base` to `config.toml`
- May start automatic sync after a successful login

Prints `verification_uri_complete` and `user_code`. The client name sent to the API is `skl@<hostname>`.

## Errors

- `device authorization expired; run skl login again`
- `device authorization was denied`
- `cannot reach API at <url>`
