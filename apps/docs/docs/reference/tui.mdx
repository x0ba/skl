# skl tui

Interactive two-pane skill browser. Running `skl` in an interactive terminal opens it. `skl ui` is an alias.

## Synopsis

```bash
skl
skl tui
skl ui
skl --no-tui
```

## Flags

- `--no-tui` (global) — print help instead of opening the TUI. `SKL_NO_TUI=1` does the same.

The fullscreen interface does not open with non-interactive or piped stdin, or in `CI`.

## What it writes

Keys have the same file effects as their CLI commands: `n` creates, `e` edits, `u` activates, `U` removes from the project, `d` deletes, and `s` syncs. Browsing and previewing read only the local library.

Keybindings are listed in [The TUI](/guide/tui).

## Errors

On an unsupported terminal, skl prints the reason and stays in the shell. Sync and delete errors appear as a short toast, not in the key-hint bar.
