# skl tui

Open the two-pane skill browser. `skl` with no subcommand in a terminal does the same. `skl ui` is an alias.

## Synopsis

```bash
skl
skl tui
skl ui
skl --no-tui
```

## Launch rules

- `--no-tui`, or `SKL_NO_TUI` set to `1`, `true`, or `yes`, prints help instead.
- When stdin or stdout is not a terminal, `skl` prints help instead.
- With `TERM=dumb`, or on a Windows console without VT support, skl prints the reason and exits `0`. Windows Terminal works.

Browsing and previewing read the library only. Sync and delete need a login.

## Keys

| Key | Action |
|---|---|
| `Up`, `Down`, `k`, `j` | Move the selection |
| `[`, `]`, `Ctrl-k`, `Ctrl-j` | Scroll the preview |
| `/` | Search. Type to filter. `Enter` keeps the filter, `Esc` clears it |
| `n` | New skill. Type a name, then `Enter`. Runs `skl create` |
| `e` | Open the selected `SKILL.md` in `$VISUAL`, then `$EDITOR`, then `vi` |
| `u` | `skl use` the selected skill in the current directory |
| `U` | `skl unuse` the selected skill in the current directory |
| `d` | Delete the selected skill. Asks `y` or `n` in a dialog. Runs `skl delete` |
| `s` | `skl sync`, and wait for it to finish |
| `r` | Reload the library and `state.db` |
| `?` | Show the key help. `?`, `q`, or `Esc` closes it |
| `q`, `Esc` | Quit from the list. `Esc` first closes an open search, help, create, or delete dialog |

Each key has the same effect on disk as the command it runs. `u` and `U` use the directory skl was started in as the project.

## Output

The bottom bar shows key hints only. Results such as `deleted <name>`, `sync finished`, `edited <path>`, and errors such as `sync: <error>` appear as a short message that disappears on its own.
