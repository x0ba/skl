# skl logout

Clear the local device token from `state.db`. The OS keyring is not required.

## Synopsis

```bash
skl logout
```

## Flags

None.

## What it writes

Deletes `meta.device_token` from `state.db`. It does not edit `config.toml` or revoke the device on the server. Any leftover OS keyring entries are unused.

## Errors

Path resolution failures from a missing config or data dir.
