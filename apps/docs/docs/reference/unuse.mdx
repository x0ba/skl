# skl unuse

Remove one or more skills from the project. The library does not change.

## Synopsis

```bash
skl unuse <skill>...
skl unuse <skill> --project <dir>
```

## Arguments and flags

- `<skill>...`. One or more skill names.
- `--project <dir>`. Project root. Default is the current directory.

## What it writes

- Deletes `.agents/skills/<name>` and the skill's directory under every extra the project lists, when skl created them.
- Removes the skill's entry from `skills.toml`.
- A background sync may run afterwards.

A real directory that `skills.toml` does not record as a copy is left in place and the command fails.

## Output

```text
unused writing-tests
  removed  agents   /path/to/project/.agents/skills/writing-tests
  updated  /path/to/project/skills.toml
```

## Errors

- `local state: specify at least one skill: skl unuse <skill>`
- `local state: <path> exists and is not a symlink; refusing to delete`
- `local state: project directory does not exist: <dir>`
