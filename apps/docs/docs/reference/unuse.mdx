# skl unuse

Remove project skill directories and entries from `skills.toml`.

## Synopsis

```bash
skl unuse <skill>…
skl unuse <skill> --project <dir>
```

## Flags

- `SKILL…` — one or more names (required)
- `--project DIR` — project directory (default: current directory)

## What it writes

Removes `.agents/skills` and configured extra destinations for each name, then updates `skills.toml`. It does not delete the personal library copy. The command may also start automatic sync.

A real directory that was not recorded as a copy is left in place.

## Errors

- `specify at least one skill: skl unuse <skill>`
- dest exists and is not a managed projection (refuses to delete an unmanaged directory)
- Config or project path resolution failures
