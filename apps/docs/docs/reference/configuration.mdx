# Configuration

skl reads `config.toml` from its configuration directory. Set `SKL_CONFIG_DIR` to use another directory. On Linux, the default file is `~/.config/skl/config.toml`. Run `skl doctor` to see the path used on this machine.

```toml
api_base = "https://api.tryskl.fyi"

[sync]
auto = true
frequency_secs = 900

[targets]
extra = ["claude-code"]

[project]
projection = "copy"
```

Unset fields use the defaults below.

## Fields

**`api_base`.** API origin, without a trailing slash. Release builds use `https://api.tryskl.fyi`; debug builds use `http://localhost:8787`. `--api-base` and `API_BASE` take precedence over this field.

**`[sync] auto`.** When `true`, login, init, use, unuse, status, create, capture, and list may start a background sync. A failed background sync does not fail the command. Default: `true`.

**`[sync] frequency_secs`.** Minimum number of seconds between a successful sync or failed automatic sync attempt. Default: `900`.

**`[targets] extra`.** Extra agent IDs to use for every activation. When empty, `skl use` writes only `.agents/skills`. `claude` is stored as `claude-code`. IDs such as `cursor` and `codex` are removed because those agents already use `.agents/skills`.

**`[project] projection`.** Default `skl use` projection. `copy` (default) materializes a real directory under `.agents/skills`. `link` creates a symlink for local live-edit. `--link` on the command line overrides this. Remote agents such as Cursor Cloud cannot follow `$HOME` symlinks. Unknown values are an error; they are not treated as `copy`.

`[targets] prompted` records that the one-time extras prompt has been shown. Do not set it manually.

## Environment

| Variable | Role |
| --- | --- |
| `API_BASE` | API origin. Same as `--api-base`. Wins over `config.toml`. |
| `SKL_CONFIG_DIR` | Directory that contains `config.toml`. |
| `SKL_DATA_DIR` | Directory that contains `state.db` and `skills/`. |
| `SKL_TOKEN` | Device token. Takes precedence over the token file and `state.db`. |
| `SKL_TOKEN_FILE` | Path to a file whose first non-empty line is the token. |
| `SKL_NO_TUI` | When set, bare `skl` prints help instead of opening the TUI. |
| `SKL_NO_PROMPT` | Skip first-run and extras prompts. |
| `SKL_YES` | Also skips prompts, like `SKL_NO_PROMPT`. |
| `SKL_NON_INTERACTIVE` | Installer binary-only mode. |
| `SKL_INSTALL_DIR` | Installer destination. Default `~/.local/bin`. |
| `SKL_DOWNLOAD_BASE` | Installer asset origin. |
| `CI` | Treat setup and install as non-interactive. |

Token sources are checked in this order: `SKL_TOKEN`, `SKL_TOKEN_FILE`, then `state.db`.

## Global flags

- `--api-base <url>` sets the API origin for this process.
- `--no-tui` prints help instead of opening the TUI.

## Data dir

The personal library is `{SKL_DATA_DIR}/skills`. The device token and local index are stored in `{SKL_DATA_DIR}/state.db`. On Linux, `SKL_DATA_DIR` defaults to `~/.local/share/skl`. On Unix, skl creates the data directory with mode `0700` and `state.db` with mode `0600`.
