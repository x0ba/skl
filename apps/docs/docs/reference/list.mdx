# skl list

List locally indexed skills from `state.db`. When logged in, also show whether they are present remotely.

## Synopsis

```bash
skl list
```

## Flags

None.

## What it writes

Does not write to disk, apart from a possible scheduled automatic sync. Prints `name`, short `tree_hash`, `source`, `path`, and `remote` (`yes`, `no`, or `-`). Skills that exist only on the server appear under `remote only`.

Without `state.db`, prints `no local skill index; run skl init first` and exits 0.

## Errors

Remote list failures print `remote list skipped` and still show the local table. Config or database open failures return an error.
