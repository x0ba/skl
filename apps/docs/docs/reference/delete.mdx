# skl delete

Delete a skill from SKL and from the local library.

## Synopsis

```bash
skl delete <skill>…
```

## Flags

- `SKILL…` — one or more names (required)

## What it writes

Calls `DELETE /v1/skills/:name`, deletes `{data_dir}/skills/<name>/`, and removes its `state.db` entries. It does not change project or home agent directories.

Requires a device token.

## Errors

- `specify at least one skill: skl delete <skill>`
- `not logged in; run skl login`
- skill is not managed by SKL (API 404 and nothing local changed)
- `refusing to delete … (not under the personal library)`
- `invalid skill name`
- `API error <status>`
