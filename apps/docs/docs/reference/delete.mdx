# skl delete

Delete one or more skills from the server and from the library. Requires a login.

## Synopsis

```bash
skl delete <skill>...
```

## Arguments

- `<skill>...`. One or more skill names.

## What it writes

For each name, skl calls `DELETE /v1/skills/<name>`, deletes `{data_dir}/skills/<name>/`, and removes the skill's rows from `state.db`. Project directories, `skills.toml`, and home agent directories do not change.

When the server returns `404` and nothing existed locally either, the command fails with `is not managed by SKL`.

## Output

```text
deleted writing-tests
```

## Errors

- `not logged in; run skl login`
- `local state: skill <name> is not managed by SKL`
- `local state: refusing to delete <path> (not under the personal library)`
- `local state: invalid skill name <name>`
- `API error <status>: <body>`
