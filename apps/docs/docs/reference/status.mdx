# skl status

Show login status, `api_base`, local skill count, and the last sync.

## Synopsis

```bash
skl status
```

## Flags

None.

## What it writes

Does not write to disk, apart from a possible scheduled automatic sync. Prints:

- `api_base`
- `token` (`yes` with a preview, or `no`)
- `config` and `state.db` paths
- `auto_sync` on or off, and `sync_frequency`
- `local_skills`
- `last_sync` summary, or `(none)`
- `sync_issue` when the last attempt failed

## Errors

If the configuration directory cannot be resolved, status still succeeds. It prints the error on the `config` line.
