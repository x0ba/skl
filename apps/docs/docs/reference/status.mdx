# skl status

Print the state of this machine's skl install.

## Synopsis

```bash
skl status
```

## Flags

None beyond the [global flags](/reference#global-flags).

## Output

```text
api_base     https://api.tryskl.fyi
token        yes (dev:alice)
config       /home/you/.config/skl/config.toml
state.db     /home/you/.local/share/skl/state.db
auto_sync    on
sync_frequency 900s
local_skills 2
last_sync    at=1789276397  uploaded=0  downloaded=0  pushed=0  conflicts=0  missing_skills=0
```

- `token` is `yes` with a preview or `no` with the login hint.
- `last_sync` is `(none)` before the first sync.
- `sync_issue` appears when the last sync attempt failed.
- `auto_sync    ran ...` appears when this command ran a background sync.

## What it writes

Nothing on disk, apart from a background sync when one is due.

## Errors

When the configuration directory cannot be resolved, status still exits `0` and prints the error on the `config` line.
