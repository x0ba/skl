# skl targets

Show or edit extra agent directories that apply to every activation (`~/.config/skl/config.toml`).

## Synopsis

```bash
skl targets
skl targets add <id>…
skl targets remove <id>…
```

## Subcommands

- no subcommand — list `.agents/skills` and configured extras
- `add` — add extra agent IDs, such as `claude-code`; rejects agents that already use `.agents/skills`
- `remove` — remove extra agent IDs; accepts aliases such as `claude`

## What it writes

`add` and `remove` update `[targets].extra` in `config.toml`. Listing makes no changes.

Output includes `canonical`, `extra`, `config`, and `ids` lines.

## Errors

- Universal ids such as `cursor` or `codex` on `add` (`… uses project .agents/skills …`)
- Unknown catalog ids
- Config dir resolution failures
