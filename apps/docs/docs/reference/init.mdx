# skl init

Import skills from home agent directories into the personal library (`~/.local/share/skl/skills`).

## Synopsis

```bash
skl init
```

## Flags

None.

## What it writes

Copies missing skills from home directories into `{data_dir}/skills`. Rebuilds the `state.db` import index from the library only. It leaves source directories and existing library skills unchanged.

May prompt once to configure extra agent directories and write `[targets]` in `config.toml`. It may also start automatic sync.

Home roots include `~/.agents/skills`, `~/.config/agents/skills`, `~/.claude/skills`, `~/.cursor/skills`, `~/.codex/skills`, and other catalog globals.

## Errors

Config or data dir resolution failures. Filesystem errors while copying.
