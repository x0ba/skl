# skl init

Copy skills from home agent directories into the library at `~/.local/share/skl/skills`.

## Synopsis

```bash
skl init
```

## Flags

None beyond the [global flags](/reference#global-flags).

## Directories scanned

`~/.agents/skills`, `~/.config/agents/skills`, and the home skills directory of every agent in skl's catalog, including `~/.claude/skills`, `~/.cursor/skills`, and `~/.codex/skills`. `skl doctor` prints the full list under `== Agent skill roots` with a skill count for each directory that exists.

## What it writes

- Copies each skill that is not already in the library to `{data_dir}/skills/<name>/`. A skill is a directory that contains `SKILL.md`.
- Rebuilds the index in `state.db` from the library.
- Leaves source directories and existing library skills unchanged.
- In a terminal, shows the extras checklist once and writes the answer to `[targets]` in `config.toml`. See [Add an extra agent directory](/how-to/extras).
- A background sync may run afterwards.

## Output

```text
Discovered 3 skill(s):
  ...
```

or `No skills found under:` followed by the directories checked.

## Errors

- `config: ...` when the config or data directory cannot be resolved.
- Filesystem errors while copying.
