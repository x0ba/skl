# skl setup

Run the initial prompts after installation: login, then import.

## Synopsis

```bash
skl setup
skl setup --non-interactive
```

## Flags

- `--non-interactive` — skip login, import, and extra-agent prompts. Prints `skl login && skl init` as the next step.

Prompts are also skipped when `CI`, `SKL_NO_PROMPT`, or `SKL_YES` is set, or when stdin is not interactive.

## What it writes

If `config.toml` has no `api_base`, setup writes the process `api_base`. This preserves the hosted API setting even when login is skipped.

Accepted prompts run `skl login` and then `skl init`. Both are optional and default to yes.

```text
Log in now? [Y/n]
Import existing skills (skl init)? [Y/n]
```

## Errors

Returns any error from an accepted `skl login` or `skl init` step.
