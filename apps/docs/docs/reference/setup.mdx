# skl setup

Ask whether to log in and whether to import skills, then run the accepted steps. The install script runs `skl setup` in a terminal.

## Synopsis

```bash
skl setup
skl setup --non-interactive
```

## Flags

- `--non-interactive`. Skip every prompt. Print `Binary is installed. Next: skl login && skl init` and exit.

Prompts are also skipped when `CI`, `SKL_NO_PROMPT`, or `SKL_YES` is set, or when stdin is not a terminal.

## Prompts

Both default to yes.

```text
Log in now? [Y/n]
Import existing skills (skl init)? [Y/n]
```

An accepted first prompt runs [`skl login`](/reference/login). An accepted second prompt runs [`skl init`](/reference/init), which may show the extras checklist.

## What it writes

If `config.toml` has no `api_base`, setup writes the API origin the process used. This keeps the hosted API setting even when you skip login.

## Errors

Any error from an accepted `skl login` or `skl init` step.
