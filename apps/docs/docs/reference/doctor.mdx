# skl doctor

Check the library, project links, token store, `state.db`, and `GET /v1/health`.

## Synopsis

```bash
skl doctor
```

## Flags

None.

## What it writes

Does not change skills, project directories, or `state.db`. It may show the one-time extras prompt and write `[targets]` if you accept.

Prints `api_base`, API health, token presence and source, config and `state.db` status, home directories, the symlink check, and current-project `skills.toml` modes. It also warns about old project layouts, host-absolute manifest paths, link projections that Cursor Cloud cannot follow, and materialized copies that differ from this machine's library.

Health probe times out after 3 seconds.

## Errors

After printing its report, doctor returns success. Its prompt is skipped under the same conditions as setup: `CI`, `SKL_NO_PROMPT`, `SKL_YES`, or non-interactive stdin.
