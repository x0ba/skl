# skl create

Create a skill in the library and open `SKILL.md` in your editor. `skl new` is an alias.

## Synopsis

```bash
skl create <skill>
skl new <skill>
```

## Arguments

- `<skill>`. The skill name. It cannot be empty, start with `.`, or contain `/` or `\`.

## What it writes

`{data_dir}/skills/<skill>/SKILL.md` with this content:

```md
---
name: <skill>
description: 
---
```

skl then indexes the skill in `state.db` and opens the file in `$VISUAL`, then `$EDITOR`, then `vi`. If the editor exits with an error, the skill stays on disk and skl prints a warning. A background sync may run afterwards.

`skl create` does not change any project directory.

## Output

```text
created writing-tests  (/home/you/.local/share/skl/skills/writing-tests)
```

## Errors

- `local state: invalid skill name <skill>`
- `local state: skill <skill> already exists in the personal library at <path>`
- Filesystem errors while creating the directory.
