# skl create

Create a skill in the personal library and open `SKILL.md` in an editor. `skl new` is an alias.

## Synopsis

```bash
skl create <skill>
skl new <skill>
```

## Flags

- `SKILL` — required name

The name cannot be empty, start with `.`, or contain `/` or `\`.

## What it writes

`{data_dir}/skills/<name>/SKILL.md` with:

```md
---
name: <skill>
description:
---
```

Indexes the skill in `state.db` and opens `$VISUAL` or `$EDITOR` (falling back to `vi`). If the editor fails, the files remain and skl prints a warning. The command may also start automatic sync.

It does not change project directories.

## Errors

- `invalid skill name`
- skill already exists in the personal library
- Filesystem errors while creating the directory
