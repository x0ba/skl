# skl

skl keeps your agent skills in one library at `~/.local/share/skl/skills`. A skill is a directory with a `SKILL.md` at its root. `skl use <name>` copies a skill from the library into `.agents/skills/<name>` in a project. `skl sync` keeps the library the same on every machine you log in from. Sync is optional. Without it, the library stays on this machine.

```bash
curl -fsSL https://tryskl.fyi/install.sh | sh
skl create writing-tests
cd /path/to/project
skl use writing-tests
```

Run `skl` with no arguments in a terminal to open the TUI.

## Getting help

File an issue at [github.com/x0ba/skl/issues](https://github.com/x0ba/skl/issues). Run `skl doctor` first and paste its output. It prints the paths skl resolved, whether a token is present, whether the API answers, and whether this machine can create directory symlinks.
