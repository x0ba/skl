# skl

skl keeps a personal library of agent skills and can sync it between machines by content hash. A skill is a directory that contains `SKILL.md`. Use `skl use` to make a library skill available in a project. It copies the skill into `.agents/skills/<name>` (so Cursor Cloud can see it) and records the name in `skills.toml`.

Sync is optional. The hosted API is [https://api.tryskl.fyi](https://api.tryskl.fyi). Skip login and the personal library stays on this machine at `~/.local/share/skl/skills`.

## Quickstart

```bash
curl -fsSL https://tryskl.fyi/install.sh | sh
```

Then:

```bash
skl login
skl init
skl sync
cd /path/to/project
skl use writing-tests
```

Run `skl init` only when you already have skills in home agent directories. `skl login` and `skl sync` are only needed to use the hosted library. Running `skl` with an interactive terminal opens the TUI.

If you want the same path with more explanation, start at [Getting started](/guide/getting-started).

## Supported platforms

The installer supports Linux `x86_64` and `aarch64`, macOS on Intel and Apple silicon, and Windows `x86_64` through Git Bash. It installs to `~/.local/bin/skl` and does not change shell configuration files. If that directory is not on `PATH`, it prints an export command for you to add.

## Getting help

File an issue at [github.com/x0ba/skl/issues](https://github.com/x0ba/skl/issues). First run `skl doctor` and include its output. It reports resolved paths, token status, API health, and whether the machine can create directory symlinks.
