# Uninstall

Run logout first to remove the local device token before deleting files. Logout does not revoke the device on the server; revoke it from the [devices page](https://www.tryskl.fyi/devices) if needed.

```bash
skl logout
```

Remove the binary, config, and data:

```bash
rm ~/.local/bin/skl
rm -rf ~/.config/skl
rm -rf ~/.local/share/skl
```

On Windows Git Bash the binary is `~/.local/bin/skl.exe`. If you set `SKL_INSTALL_DIR`, `SKL_CONFIG_DIR`, or `SKL_DATA_DIR`, delete those paths instead.

This does not remove project `.agents/skills` directories or `skills.toml`; delete them from each project if needed. skl does not own home agent directories such as `~/.claude/skills`, so it leaves them in place.
